# 🩸 Blood Bank Management System

A web-based platform designed to efficiently track blood inventory, manage donor and recipient records, and process blood requests in real time.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP
* **Database:** MySQL (phpMyAdmin)
* **Server Environment:** XAMPP (Apache & MySQL)

---

## 🚀 How to Run the Project

1. **Setup Project Directory**
   Copy the project folder and paste it into the XAMPP `htdocs` directory:
   `C:\xampp\htdocs\`

2. **Start Local Server**
   Open the **XAMPP Control Panel** and start both **Apache** and **MySQL**.

3. **Configure Database**
   * Open your browser and navigate to `http://localhost/phpmyadmin`
   * Create a new database named `blood_bank`
   * Go to the **Import** tab and select the `blood_bank.sql` file from your project folder to import the schema and data.

4. **Launch Application**
   Open your web browser and visit:
   `http://localhost/blood_bank`
